# Проверки продукта

Дата: 26 октября 2026.

## Автоматические проверки

- `npm run build` — успешно: TypeScript и production-сборка Vite.
- `npm run lint` — успешно, без замечаний.
- `npm audit` — 0 уязвимостей во всех зависимостях.
- Отдельного unit/e2e набора в продукте нет; критические сценарии проверены в браузере.

## Браузерная проверка

- Production preview проверен визуально на настольном и мобильном представлении.
- Ширины 320, 360, 390, 768, 1024 и 1440 px: горизонтального переполнения нет.
- Мобильная навигация открывает ссылки разделов.
- Категория «Завтраки» показывает три позиции; фильтр «Растительные» оставляет три позиции из меню.
- Пустая обязательная форма блокирует запрос; бронирование с тестовым номером и будущей датой прошло, текст скопирован, подтверждающий тост показан. Настроенного внешнего канала нет, данные вовне не отправлялись.
- Сгенерированные WebP-изображения загрузились в браузере.

## Известные настройки перед сайтом конкретного заведения

Настроить и подтвердить адрес, телефон, часы, канал бронирования, меню, цены, состав и аллергенную информацию. В текущем демонстрационном продукте эти поля намеренно не заявлены как реальные.
