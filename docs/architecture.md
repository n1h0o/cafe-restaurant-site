# Архитектура

Статическое одностраничное React/TypeScript-приложение на Vite. Внешний сервер не нужен: контент заведения и меню находятся в `src/config.ts`, взаимодействия в `src/App.tsx`, визуальная система в `src/styles.css`.

Форма бронирования валидируется браузером, собирает текст запроса и передаёт его только при пользовательском действии. В конфигурации можно задать ссылку канала (например, WhatsApp URL с `?text=`); иначе приложение предлагает скопировать запрос. Формы не сохраняются и не отправляются автоматически. Публикация самого сайта требует отдельно настроенного хостинга.

Для передачи в WhatsApp `bookingUrl` задаётся как URL адресата с параметром `?text=`; приложение добавляет только URL-кодированный текст формы. Пустой канал остаётся безопасным режимом копирования.
