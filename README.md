# ДЕНЬ — сайт городского кафе

Адаптивный сайт кафе с редакционной визуальной системой: тёплая бумажная палитра, крупная журнальная типографика, авторские изображения завтрака, выпечки и интерьера. Интерфейс ведёт посетителя от формата и меню к запросу на бронирование.

## Возможности

- Навигация для настольных и мобильных экранов.
- Меню с категориями, фильтрами по составу и раскрывающимися описаниями; FAQ с ответами о бронировании, демонстрационных данных и аллергенах.
- Бронирование с проверкой даты, контактным телефоном, временем и числом гостей.
- Отправка в настроенный канал владельца либо подготовка текста запроса для копирования. Данные формы не сохраняются.
- Редактируемые бренд, меню, валюта, часы, адрес, телефон и канал бронирования в `src/config.ts`.
- SEO и Open Graph, доступная клавиатурная навигация, адаптивность и поддержка reduced motion.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Проверки и production-сборка:

```bash
npm run lint
npm run build
npm audit
npm run preview
```

## Настройка под заведение

Измените `src/config.ts`: контакты, город, адрес, расписание, канал бронирования, валюту, ссылки на соцсети, текст и меню. Интерфейс и контент сейчас на русском; тексты локализуют при адаптации под язык конкретного рынка. Позиции меню и цены сейчас — образец для демонстрации. Аллергены и фактические цены заведение должно подтвердить самостоятельно. Без настроенных контактов форма подготовит текст и скопирует его на устройство гостя, не заявляя о подтверждённой брони.
