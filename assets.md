# Медиа и лицензии

Три фотографии (завтрак, выпечка и интерьер) сгенерированы инструментом OpenAI Image Gen для этого демонстрационного проекта студии. Они не изображают подтверждённое реальное кафе и не выдаются за клиентские материалы. В репозитории хранятся оптимизированные WebP-файлы в `public/images/`; исходные генерации остаются вне репозитория.

Название «ДЕНЬ» — демонстрационный бренд. Шрифт DM Sans и DM Serif Display подключены через Google Fonts; перед работой без интернета их можно локально разместить согласно лицензии SIL Open Font License.
